# 🚀 A Clear Guide to SQL

Welcome to the SQL Learning Hub! This repository is designed to provide a clear, concise, and structured guide to learning SQL (Structured Query Language). Whether you're a beginner taking your first steps in data or a professional looking to refresh your skills, you'll find the resources here helpful


---

## 📚 Table of Contents

This repository is organized into chapterss and supplementary PDF guides to help you learn progressively.

### Chapters

The core concepts of SQL are broken down into five chapters. It's recommended to go through them in order.

* **Chapter 1: Introduction to Databases & Basic Queries**
    * What is SQL?
    * Setting up your environment.
    * The `SELECT` and `FROM` clauses.
    * Basic filtering with `WHERE`.

* **Chapter 2: Filtering, Sorting, and Calculating Data**
    * Advanced `WHERE` conditions with `AND`, `OR`, `NOT`.
    * Sorting results with `ORDER BY`.
    * Using `LIMIT` to restrict results.
    * Working with `NULL` values.

* **Chapter 3: Aggregate Functions & Grouping**
    * Understanding `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`.
    * Grouping data with `GROUP BY`.
    * Filtering grouped data with `HAVING`.

* **Chapter 4: Data Manipulation Language (DML)**
    * Adding new data with `INSERT`.
    * Modifying existing data with `UPDATE`.
    * Removing data with `DELETE`.

* **Chapter 5: Advanced SQL Concepts**
    * Writing Subqueries (Nested Queries).
    * Common Table Expressions (CTEs) with `WITH`.
    * Introduction to `CASE` statements.

2.  **[Advanced_SQL_Joins.pdf](./Advanced_SQL_Joins.pdf)**
